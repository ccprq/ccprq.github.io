Regular Expression (kısaca Regex veya Regexp), metin içindeki kalıpları tanımlamaya yarayan özel bir dildir. C# dilinde System.Text.RegularExpressions namespace'i altında gelir ve NFA (Nondeterministic Finite Automaton) tabanlı bir motor kullanır. 1951'de matematikçi Stephen Cole Kleene'nin resmi dil teorisiyle temellenen bu yapı, günümüzde metin doğrulama, arama, ayrıştırma ve dönüştürme işlemlerinin vazgeçilmezi hâline gelmiştir.

C# regex motoru Perl uyumlu (PCRE benzeri) olup lookahead, lookbehind, isimli gruplar, atomic gruplar ve balancing gruplar gibi ileri düzey özellikleri destekler.

📌 Verbatim String Zorunluluğu C#'ta ters eğik çizgi (\) hem string escape hem de regex escape karakteridir. \d yazmak için normal string'de "\\d" yazmanız gerekir. Bu karışıklığı önlemek için daima @"\d" verbatim string sözdizimini kullanın.

1. Giriş & Temel API

1.1 Temel Sınıflar

1.2 Temel Kullanım Örnekleri

using System.Text.RegularExpressions;

// ──────────────────────────────────────────
// 1. IsMatch — Eşleşme var mı? (bool döner)
// ──────────────────────────────────────────
bool ok = Regex.IsMatch("hello world", @"\bworld\b");  // true

// ──────────────────────────────────────────
// 2. Match — İlk eşleşmeyi bul
// ──────────────────────────────────────────
Match m = Regex.Match("abc123def", @"\d+");
if (m.Success)
{
    m.Value   // "123"
    m.Index   // 3  (string içindeki başlangıç konumu)
    m.Length  // 3  (kaç karakter uzunluk)
}

// ──────────────────────────────────────────
// 3. Matches — Tüm eşleşmeleri bul
// ──────────────────────────────────────────
foreach (Match match in Regex.Matches("a1 b2 c3", @"\d"))
    Console.WriteLine(match.Value);  // "1", "2", "3" (sırayla)

// ──────────────────────────────────────────
// 4. Replace — Değiştir
// ──────────────────────────────────────────
string r1 = Regex.Replace("foo   bar", @"\s+", " ");  // "foo bar"

// ──────────────────────────────────────────
// 5. Split — Böl
// ──────────────────────────────────────────
string[] parts = Regex.Split("a,b;c d", @"[,;\s]+");
// ["a", "b", "c", "d"]

// ──────────────────────────────────────────
// 6. Compiled — Performans için önceden derle
// ──────────────────────────────────────────
var rx = new Regex(@"\d+", RegexOptions.Compiled);

// ──────────────────────────────────────────
// 7. Timeout — ReDoS koruması
// ──────────────────────────────────────────
var safe = new Regex(@".+", RegexOptions.None,
    TimeSpan.FromMilliseconds(200));

// ──────────────────────────────────────────
// 8. .NET 7+ Source Generator (en hızlı)
// ──────────────────────────────────────────
[GeneratedRegex(@"\d+", RegexOptions.Compiled)]
private static partial Regex DigitRegex();

2. Çapalar (Anchors)

Çapalar herhangi bir karakteri yutmaz; yalnızca string içindeki belirli bir konumu doğrularlar. Bir regex motorunun "nereden bakacağını" belirler.

^ Anchor
Satır / string başı. Varsayılanda string'in en başını işaret eder. Multiline modunda her satır başını da yakalar.
Desen: ^Merhaba
✅Merhaba dünyaBaşta
❌Dünya MerhabaBaşta değil
✅satır1\nMerhabaMultiline ile
$ Anchor
Satır / string sonu. Varsayılanda string sonunu işaret eder. Son \n öncesine de eşleşebilir. Multiline modunda her satır sonunu da yakalar.
Desen: dünya$
✅Merhaba dünyaSonda
❌dünya barışSonda değil
\b Anchor
Kelime sınırı. \w (kelime karakteri) ile \W (kelime dışı) arasındaki sıfır-genişlikli geçiş noktasını işaret eder. String başı/sonu da kelime sınırı sayılır.
Desen: \bcat\b
✅I have a cat
✅cat sat
❌concatenate"cat" kelime ortasında
❌bobcatSolunda \w var
\B Anchor
Kelime sınırı değil. \b'nin tam tersidir. İki kelime karakteri arasındaki ya da iki kelime-dışı karakter arasındaki konumu işaret eder.
Desen: \Bcat\B
✅concatenateHer iki yanı \w
❌I have a catKelime sınırı var
\A Anchor
Mutlak string başı. ^'dan farklı olarak Multiline modunda bile yalnızca string'in başını işaret eder. Satır başına uymaz.
Desen: \AStart
✅Start\notherString başı
❌line\nStartMultiline'da bile eşleşmez
\Z   \z Anchor
Mutlak string sonu. \Z: string sonu veya son satır sonlandırıcısından önce. \z: kesinlikle en son karakter konumu.
Desen: end\Z
✅the end
✅the end\n\Z için son \n öncesi
❌the end\nmore
\G Anchor
Önceki eşleşme sonu. Matches() veya ardışık çağrılarda, son eşleşmenin bittiği konumdan başlamayı zorlar. Tokenizer yazarken çok kullanışlıdır.
Desen: \G\d+ üzerinde "123abc456"
✅123abc456İlk eşleşme
❌123abc456Araya harf girdiği için durur

3. Karakter Sınıfları

3.1 Kısaltma Sınıfları — \w, \d, \s ve Büyük Halleri

Kısaltma sınıfları (shorthand character classes), tek bir sembolle çok sayıda karakteri temsil eder. C# regex'in en sık kullanılan yapı taşlarıdır.

\w Kelime Karakteri
Word character. [a-zA-Z0-9_]'ye eşdeğerdir. Unicode modunda tüm dillerin harfleri ve rakamları da dahildir (ğ, ü, ş, 汉, Ä gibi).
Desen: \w+
✅hello
✅_private
✅abc123
❌!@#$Noktalama karakterleri
Karşılaştırma: \w vs \w+
📍\w → tek karakter: "hello"
📍\w+ → bir veya daha fazla: "hello"
📍\w* → sıfır veya daha fazla: "" de eşleşir
📍\w{3} → tam 3 karakter: "hello"
\W Kelime Dışı
\w'nin tam tersi. Harf, rakam veya alt çizgi olmayan her karakteri eşler: boşluk, noktalama, özel karakterler vb.
Desen: \W+
✅hello, worldVirgül + boşluk
✅foo!bar
❌helloworldHepsi \w
Kullanım: Kelimeleri ayır
💡Regex.Split("a, b; c", @"\W+")
→ ["a", "b", "c"]
\d Rakam
Digit. [0-9]'a eşdeğerdir. Unicode modunda tüm dillerin rakamları da dahildir (Arapça ٣, Hint rakamları ३ vb).
Desen: \d+
✅abc123def
✅0
❌abcRakam yok
Karşılaştırma: \d vs \d+
📍\d → tek rakam: "abc123"
📍\d+ → tam sayı: "abc123"
📍\d{4} → 4 haneli: "2024-01"
📍\d{2,4} → 2-4 hane: "24", "2024"
\D Rakam Dışı
\d'nin tam tersi. Rakam olmayan her karakteri eşler: harfler, boşluklar, noktalamalar vb.
Desen: \D+
✅abc123
✅123def
❌12345Tümü rakam
Kullanım: Sadece rakamları elde et
💡Regex.Replace("Tel: 0532-111", @"\D", "")
→ "0532111"
\s Boşluk
Whitespace. Boşluk karakterlerini eşler: space (' '), tab (\t), newline (\n), carriage return (\r), form feed (\f), vertical tab (\v).
Desen: \s+
✅foo barÇoklu boşluk
✅line1\nline2Newline
✅col1\tcol2Tab
❌nospace
Kullanım: Boşlukları normalize et
💡Regex.Replace("a b\tc", @"\s+", " ")
→ "a b c"
\S Boşluk Dışı
\s'nin tam tersi. Boşluk olmayan her karakteri eşler. Genellikle bir token'ı (sözcük, etiket, değer) yakalamak için kullanılır.
Desen: \S+
✅hello world
✅ trimmed Boşlukları atlar
❌ Sadece boşluk
. Herhangi Karakter
Nokta (wildcard). Newline (\n) HARİÇ herhangi bir karakteri eşler. Singleline bayrağıyla newline'ı da eşler.
Desen: a.b
✅aXb
✅a b
✅a1b
❌a\nbVarsayılanda newline eşleşmez
. vs .+ vs .*
📍. → tam olarak 1 karakter
📍.+ → 1 veya daha fazla (boş eşleşmez)
📍.* → 0 veya daha fazla (boş da eşleşir)
💡 Büyük harf = ters anlam kuralı C# regex'te bir kısaltmanın büyük harfi, daima onun tersini temsil eder: \w kelime karakteri ↔ \W kelime dışı. \d rakam ↔ \D rakam dışı. \s boşluk ↔ \S boşluk dışı.

4. Niceleyiciler (Quantifiers)

Niceleyiciler, önündeki öğenin kaç kez tekrarlanacağını belirtir. Varsayılan olarak greedy (açgözlü) çalışırlar.

SembolAnlamıEşdeğeriLazy HaliÖrnek
*0 veya daha fazla{0,}*?ab* → "a", "ab", "abbb"
+1 veya daha fazla{1,}+?ab+ → "ab", "abbb"
?0 veya 1 (opsiyonel){0,1}??colou?r → "color", "colour"
{n}Tam n kez——\d{4} → "2024"
{n,}En az n kez—{n,}?\w{3,} → "abc", "hello"
{n,m}n ile m arasında—{n,m}?\d{2,4} → "12","123","1234"

4.1 Greedy vs Lazy — En Kritik Fark

Bu farkı anlamak, regex yazarken en çok hata yapılan konudur.

🐊 Greedy (Açgözlü) — Varsayılan

Mümkün olan en uzun metni yakalar. Motor önce her şeyi alır, sonra gerekirse geri bırakır (backtrack).

String: <b>bold</b> ve <i>italic</i>
🎯Desen: <.+>
⚠️Eşleşme: <b>bold</b> ve <i>italic</i>
💬Tüm string'i yuttu!
🌿 Lazy (Tembel) — ? Ekle

Mümkün olan en kısa metni yakalar. Gereken minimum kadar alır.

String: <b>bold</b> ve <i>italic</i>
🎯Desen: <.+?>
✅1. eşleşme: <b>
✅2. eşleşme: </b>
💬Her tag ayrı ayrı yakalandı!
🔢 + ile +? Karşılaştırması
String: "aaa bbb"
📍\w+ → aaa (greedy, max al)
📍\w+? → a (lazy, min al)
🔢 * ile *? Karşılaştırması
String: "((abc))"
📍\(.*\) → ((abc)) (dış)
📍\(.*?\) → (abc) (iç)
// Pratik örnek: JSON değeri çekme
string json = @"{""name"":""Ali"",""city"":""Istanbul""}";

// GREEDY — Yanlış sonuç!
Regex.Match(json, @""".*""").Value
// → "name":"Ali","city":"Istanbul" (fazla yuttu)

// LAZY — Doğru sonuç
Regex.Match(json, @""".*?""").Value
// → "name" (ilk key)

foreach (Match m in Regex.Matches(json, @"""(.*?)"""))
    Console.WriteLine(m.Groups[1].Value);
// name, Ali, city, Istanbul

5. Gruplar & Yakalama

SözdizimTürAçıklama
(abc)Yakalama grubuEşleşmeyi yakalar ve numaralandırır. Groups[1], [2]… ile erişilir.
(?:abc)Non-capturingGruplar ama yakalamaz. Gruplama için performanslı yol.
(?<name>abc)İsimli grupGruba isim verir. Groups["name"] ile erişilir.
(?>abc)Atomic grupBacktracking'i önler. Performans ve doğruluk için.
(?<A>-(?<B>))+Balancing grupNested parantez/tag dengeleme için özgün .NET özelliği.
// Yakalama grubu — tarih ayrıştırma
Match m = Regex.Match("2024-03-28", @"(\d{4})-(\d{2})-(\d{2})");
m.Groups[0].Value  // "2024-03-28" — tüm eşleşme (her zaman Group[0])
m.Groups[1].Value  // "2024" — yıl
m.Groups[2].Value  // "03"   — ay
m.Groups[3].Value  // "28"   — gün

// Non-capturing grup — yakalamadan gruplama
Regex.IsMatch("colour", @"colo(?:u)?r"); // true, u opsiyonel ama kaydedilmez

// İsimli grup — okunabilir yakalama
Match n = Regex.Match("2024-03-28",
    @"(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})");
n.Groups["year"].Value   // "2024"
n.Groups["month"].Value  // "03"
n.Groups["day"].Value    // "28"

// Grup isimlerini listele
string[] names = new Regex(@"(?<year>\d{4})").GetGroupNames();
// ["0", "year"]

// Tekrarlayan gruplarda CaptureCollection
Match rep = Regex.Match("aababc", @"(a(b)?)*");
foreach (Capture c in rep.Groups[1].Captures)
    Console.Write(c.Value + " ");  // a ab ab

6. Lookahead & Lookbehind

Lookaround yapıları, eşleşme noktasının önünde (lookahead) veya arkasında (lookbehind) ne olduğunu karakterleri yutmadan kontrol eder. Bu nedenle sıfır genişlikli doğrulamalar (zero-width assertions) olarak da bilinirler.

(?=...) Positive Lookahead
Sağından belirtilen gelmeli. Eşleşme konumunun sağında verilen desen bulunmalıdır, ama o desen yakalanmaz.
Desen: \d+(?= TL)
✅fiyat: 150 TL"TL" yakalanmaz
❌fiyat: 150 EUR
Desen: \w+(?=ing)
✅swimming
✅running
(?!...) Negative Lookahead
Sağından belirtilen gelmemeli. Eşleşme noktasının sağında verilen desen bulunmamalıdır.
Desen: foo(?!bar)
✅fooXYZbar gelmiyor
❌foobarbar geliyor
Desen: \b(?!un)\w+
✅happy
❌unhappy"un" ile başlıyor
(?<=...) Positive Lookbehind
Solundan belirtilen gelmiş olmalı. Eşleşme noktasının solunda verilen desen mevcut olmalıdır, ama yakalanmaz.
Desen: (?<=\$)\d+
✅$500$ yakalanmaz
❌€500
Desen: (?<=\bfoo)\w+
✅foobar
❌barfoo
(?<!...) Negative Lookbehind
Solundan belirtilen gelmemiş olmalı. Eşleşme noktasının solunda verilen desen bulunmamalıdır.
Desen: (?<!\d)\d+
✅abc123Başı sayı değil
❌1234Önünde rakam var
Desen: (?<!un)\w+happy
✅happy
❌unhappy
// Güçlü şifre doğrulama (tüm lookahead'ler birlikte)
string pwPattern = @"^
    (?=.*[A-Z])          # En az bir büyük harf
    (?=.*[a-z])          # En az bir küçük harf
    (?=.*\d)             # En az bir rakam
    (?=.*[!@#$%^&*])     # En az bir özel karakter
    .{8,}                # Minimum 8 karakter
$";
var rx = new Regex(pwPattern, RegexOptions.IgnorePatternWhitespace);
rx.IsMatch("MyP@ssw0rd");   // true
rx.IsMatch("password");     // false (büyük harf yok, özel karakter yok)

7. Alternasyon (|)

| operatörü regex'te OR (veya) mantığı gibi çalışır. Motor soldan sağa sırayla dener; ilk eşleşende durur. Bu nedenle sıralama önemlidir.

⚠️ Sıralama Kuralı Alternatiflerin uzundan kısaya doğru sıralanması gerekir. ab|abc yazdığınızda "ab" bulununca durur ve "abc" hiç denenmez. Doğrusu: abc|ab. 
// Temel alternasyon
Regex.IsMatch("cat", @"cat|dog|bird");   // true
Regex.IsMatch("fish", @"cat|dog|bird");  // false

// Grupla sınırlı alternasyon
Regex.IsMatch("color",  @"colo(?:u|)r");  // true
Regex.IsMatch("colour", @"colo(?:u|)r");  // true

// Dosya uzantısı doğrulama
Regex.IsMatch("photo.JPEG",
    @"(?i)\.(jpg|jpeg|png|gif|webp|svg)$");  // true

// HTTP durum kodları
var rx = new Regex(@"^(200|201|204|301|302|400|401|403|404|500)$");
rx.IsMatch("404");  // true

8. Geri Referanslar (Backreferences)

Geri referanslar, daha önce yakalanmış bir grubu aynı metni tekrar eşleştirmek için kullanır. Belge doğrulama ve tutarlılık kontrollerinde çok güçlüdür.

SözdizimReferans TürüÖrnek
\1, \2…Numaralı grup referansı(\w+)\s\1 → "the the"
\k<name>İsimli grup referansı(?<w>\w+)\s\k<w>
$1, $2…Replace içinde numaraRegex.Replace(s, p, "$2-$1")
${name}Replace içinde isimRegex.Replace(s, p, "${day}/${month}")
// Tekrarlanan kelime bulma
var doubled = new Regex(@"\b(\w+)\s+\1\b", RegexOptions.IgnoreCase);
doubled.IsMatch("the the");     // true
doubled.IsMatch("The THE");     // true (IgnoreCase)
doubled.IsMatch("the cat");     // false

// HTML eşleşen tag kontrolü — açılış = kapanış
string tagPat = @"<(?<tag>\w+)>.*?</\k<tag>>";
Regex.IsMatch("<b>bold</b>", tagPat);   // true
Regex.IsMatch("<b>bold</i>", tagPat);   // false! (b ≠ i)

// Tırnak içindeki string eşleştirme (tek veya çift tırnak)
string quotePat = @"(['""]).*?\1";
Regex.IsMatch("'hello'", quotePat);  // true (tek tırnak)
Regex.IsMatch("""world""", quotePat);  // true (çift tırnak)
Regex.IsMatch("'mixed\"", quotePat);  // false (farklı tırnak)

9. Bayraklar (RegexOptions)

BayrakInlineAçıklama
RegexOptions.IgnoreCase(?i)Büyük/küçük harf duyarsız. "abc" ile "ABC" eşleşir.
RegexOptions.Multiline(?m)^ ve $ her satır başı/sonu için çalışır.
RegexOptions.Singleline(?s). newline'ı da kapsar.
RegexOptions.IgnorePatternWhitespace(?x)Pattern içinde boşluk ve # yorum yazılabilir (okunabilir regex).
RegexOptions.ExplicitCapture(?n)Yalnızca (?<name>...) isimli gruplar yakalanır.
RegexOptions.Compiled—MSIL'e derler; ilk çalıştırma yavaş ama tekrarlarda çok hızlı.
RegexOptions.RightToLeft—Sağdan sola arar (RTL dil desteği için).
RegexOptions.CultureInvariant—Kültür bağımsız karşılaştırma. Sunucu-side kod için önerilir.
RegexOptions.NonBacktracking.NET 7+—Lineer O(n) zaman garantisi. ReDoS'a karşı tam koruma.

var rx = new Regex(@"\bhello\b",
    RegexOptions.IgnoreCase |
    RegexOptions.Multiline  |
    RegexOptions.Compiled);

// IgnorePatternWhitespace ile okunabilir regex
var dateRx = new Regex(@"
    (?<year>  \d{4})   # 4 haneli yıl

    -                   # ayraç
    (?<day>   \d{2})   # 2 haneli gün
", RegexOptions.IgnorePatternWhitespace);

// Multiline — her satır başını ^ ile yakala
string text = "line1\nline2\nline3";

// "line1", "line2", "line3"

// NonBacktracking — güvenli kullanıcı girdisi için (.NET 7+)
var safe = new Regex(@"^(\w+\s?)*$", RegexOptions.NonBacktracking);
// Kötü pattern ama backtracking olmadığı için güvenli

12. Atomic Gruplar (?>...)

Atomic gruplar, motor bir kez eşleştikten sonra o kısma geri dönmesini (backtrack) engeller. Bu hem performansı artırır hem de istenmeyen backtracking davranışlarını önler.

// Normal grup — backtracking yapar
Regex.IsMatch("aab", @"(a+)b");
// (a+) önce "aa" alır, b bulamaz, backtrack: "a" alır, b bulur → true

// Atomic grup — backtracking yapmaz
Regex.IsMatch("aab", @"(?>a+)b");
// (?>a+) "aa" alır, b bulamaz, backtrack YAPMAZ → false

// Pratik: Anahtar kelime ardından zorunlu token
string pat = @"(?>\w+)\s*=";
// Kelimeyi bir bütün olarak alır, sonra = arar; daha hızlı

13. Balancing Gruplar İleri Düzey

.NET regex motorunun kendine özgü özelliğidir. İç içe geçmiş yapıları (parantezler, etiketler) saymak ve dengelemek için kullanılır. Diğer regex motorlarında yoktur.

// Dengeli parantezleri eşleştirme
string balanced = @"
    ^                   # Baştan başla
    [^()]*              # Parantez olmayan karakterler
    (?:
        (?<open> \()    # Açılan parantez → stack'e ekle
        [^()]*
        |
        (?<-open> \))   # Kapanan parantez → stack'ten çıkar
        [^()]*
    )*
    (?(open)(?!))       # Stack boş olmalı (hâlâ açık parantez var mı?)
    $                   # Sona kadar
";

var rx = new Regex(balanced, RegexOptions.IgnorePatternWhitespace);
rx.IsMatch("(a(b)c)");    // true  — dengeli
rx.IsMatch("(a(b)c");     // false — açık parantez var
rx.IsMatch("a)b(c");      // false — önce kapanış

14. Performans & ReDoS

🚨 ReDoS (Regular Expression Denial of Service) Kötü yazılmış regex'ler, özellikle iç içe niceleyiciler içerenler, üstel sürede çalışabilir ve uygulamayı durdurabilir. Kullanıcı girdisi üzerinde regex çalıştırırken mutlaka timeout belirleyin veya .NET 7+'da NonBacktracking kullanın.
